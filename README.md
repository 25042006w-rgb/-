# WebType — Типографика в Web

**Live:** ВСТАВЬТЕ_ССЫЛКУ_НА_GITHUB_PAGES

Учебный адаптивный сайт на тему «Типографика в Web».

## Технологии

- HTML5
- CSS3
- Carbon Design System
- JavaScript
- Git / GitHub
- GitHub Pages

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Публикация

1. Создайте GitHub-репозиторий.
2. Загрузите все файлы проекта.
3. В Settings → Pages выберите публикацию из ветки `main`.
4. Скопируйте полученную ссылку в этот README и в `read.md`.

## Структура

- `index.html` — главная;
- `basics.html` — основы типографики;
- `hierarchy.html` — иерархия текста;
- `fonts.html` — веб-шрифты;
- `practice.html` — практическая часть;
- `about.html` — информация о проекте;
- `css/style.css` — собственные стили;
- `js/main.js` — интерактив.
