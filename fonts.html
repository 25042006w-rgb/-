Шрифты в Web

Браузер может использовать системные шрифты или загружать специальные веб-шрифты вместе со страницей.

Web Fonts

Web Font — шрифт, который доступен браузеру через сеть или локальные ресурсы проекта. Для производительности желательно использовать современные форматы и ограничивать набор начертаний.

Форматы

  • WOFF2 — современный сжатый формат для Web.
  • WOFF — широко поддерживаемый веб-формат.
  • TTF/OTF — универсальные форматы шрифтов, но обычно менее оптимальны для Web.

Пример @font-face

@font-face {
  font-family: "MyFont";
  src: url("fonts/myfont.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
}
